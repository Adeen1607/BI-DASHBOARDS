# Data and Privacy

## Data Classification

The dashboard case studies in this repository use public or study-purpose datasets. They are not derived from confidential employer systems, private client databases, or production customer records.

## Publishing Principles

- Do not commit credentials, access tokens, or private connection strings.
- Do not publish directly identifying personal information.
- Record the original data source and licence when a project is refreshed.
- Separate observed records from simulated or generated records.
- Use aggregated views when record-level detail is unnecessary.
- Document transformations that materially affect interpretation.
- Preserve limitations and uncertainty in presentations and dashboard notes.

## Reproducibility Standard

Future project updates should include:

1. A source reference and access date.
2. A data dictionary or field description.
3. A repeatable cleaning or transformation script.
4. KPI definitions.
5. Known limitations and assumptions.
6. A static preview suitable for review without proprietary software.

## Confidentiality Statement

No files in this repository should be interpreted as representing the data, reporting systems, or performance of a current or former employer or client.
