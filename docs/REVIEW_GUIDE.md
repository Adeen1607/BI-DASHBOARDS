# Dashboard Review Guide

This guide provides a fast review path for recruiters, hiring managers, and analysts.

## Five-Minute Review

1. Start with `Online Sales Data Visualization.pptx` for a business-oriented dashboard example.
2. Review `Data Insights From dashboards.pptx` for the accompanying analytical narrative.
3. Open `COVID-19 DASHBOARD.pptx` for an example involving time and geographic comparisons.
4. If Tableau is available, download the corresponding `.twbx` files to inspect filters, interactions, and workbook structure.

## Evaluation Areas

### Business framing

- Is the purpose of the dashboard clear?
- Do the selected KPIs support the intended question?
- Can a non-technical viewer understand the main observations?

### Visual design

- Is information prioritized through hierarchy and layout?
- Are chart types appropriate for the comparisons being made?
- Are colour, labels, and filters used consistently?

### Analytical discipline

- Are comparisons made at compatible levels of detail?
- Are trends distinguished from isolated observations?
- Are limitations and data-source constraints visible?

### Decision support

- Does the dashboard help identify where further investigation is needed?
- Can the viewer move from a high-level KPI to a supporting breakdown?
- Are presentation slides written in business language rather than tool-specific terminology?
